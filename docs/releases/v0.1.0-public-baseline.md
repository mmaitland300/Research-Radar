# v0.1.0 Public Baseline

Date: 2026-05-31

Intended tag: `v0.1.0-public-baseline`

This release captures Research Radar as a public, reviewable prototype. It is a
baseline for portfolio and engineering review, not a claim that the ranking
system is validated for production use.

## Highlights

- Live app with search, recommended feeds, paper detail, trends, and evaluation.
- No-key local demo through `npm run demo:local` using fixture-mode API data.
- Full Postgres path for OpenAlex-backed corpus work, pgvector embeddings, API,
  and Next.js web UI.
- Ranked recommendation families with visible ranking provenance and evaluation
  surfaces.
- Similar-papers UI backed by stored embeddings when an embedding version is
  configured.
- CI-backed Python and web checks on `main`.

## Review Path

1. Try the live app at [radar.mmaitland.dev](https://radar.mmaitland.dev).
2. Run the fixture demo with `npm run demo:local`.
3. Read [EVALUATION.md](../../EVALUATION.md) for current evidence boundaries.
4. Read [docs/public-roadmap.md](../public-roadmap.md) for the next public work.
5. Use [docs/release-smoke-checklist.md](../release-smoke-checklist.md) before
   comparing a release tag with the deployed app.

## Known Limits

- Corpus scope is intentionally narrow: TISMIR + JAES.
- Evaluation is still proxy/single-reviewer only unless a specific audit artifact
  says otherwise.
- Bridge diagnostics are experimental.
- Emerging may be ordered by the bounded ML scorer when the live gate is
  configured; evaluation is still not a validation claim.
- The live deployment is a moving surface; archived audit records are the stable
  comparison points.
- `Idea Graph` is out of scope for V1.

## Maintainer Notes

- Keep release notes precise about current evidence.
- Prefer small, tagged baselines over broad claims.
- Any future learned-scoring rollout should point to the relevant gate checks,
  run ids, scorer versions, and audit bundles.
